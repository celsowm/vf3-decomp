# 0x8C096258 indexed node flag merge

The baseline inventory records a 178-byte function at `0x8C096258`. Its
captured entry is immediately after the callee-save pushes at `0x8C096248`;
the five-window snapshots include the stack page, so the port models the
observable stack frame instead of assuming the saves are invisible.

The routine resolves a signed 8-bit node index through the table at
`0x0C2CF834`, computes eight mask flags from the table at `r6`, shifts those
flags by the caller's selector, and ORs the result into three words at
`r9+0x138..0x140`. It also pushes PR at `SP-4`, then restores `r8-r14` from
the callee-save frame and exits with `SP+28`.

The replay uses 128 unique paired register+RAM cases captured from states 37,
40, and 41. The cases span five RAM windows, including node tables, global
state, and the full stack page. `tests/f096258_replay.c` passes all 128 cases;
the same replay is in `portcheck` and `tools/golden_bindings.json`.

Capture output is ignored under
`extract/analysis/goldens_96258_states37_40_41/`. The associated watch recipe
is `tools/watch/vf3_96258_ram.txt`.
