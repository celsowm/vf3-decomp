# 0x8C09F9A8 signed-guard path

The baseline span is 46 bytes. It masks r5 by r2 and performs a signed
comparison against r4. When masked r5 is greater, `bt/s` returns before the
FPU continuation at `0x8C09F9B2`. The branch delay slot shifts r6 left by eight;
the comparison leaves SR.T set. This path also leaves the saved PR word at
`r15-4` and returns with r15 advanced by four.

`tools/watch/vf3_f9f9a8_full.txt` captures the function and helper with eight
RAM windows. In the 64 unique function cases, 47 take the guard and 17 call
`0x8C09F354`. The guard path passes 47/47 paired register and RAM replays.
The 17 FPU continuations are skipped by the harness until the helper's full
vector update and RAM effects are ported.
